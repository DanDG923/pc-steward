# Security policy

PC Steward is pre-release software with no supported release. It is not ready for distribution, so there are no supported versions to patch.

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue.

Use GitHub's private reporting form: go to the **Security** tab of this repository and choose **Report a vulnerability**.

Please include the commit you looked at, what you found, and steps to reproduce it if you can. You will get a reply when the owner has reviewed the report. There is no bounty.

## Scope

Reports about the desktop app, the elevated update helper, the owner-only install and signing scripts, and the CI workflows are all in scope. The threat model is in [docs/architecture/THREAT_MODEL.md](docs/architecture/THREAT_MODEL.md).
