# Superseded browser visual reference

> **Archived reference only.** This folder is not the PC Steward application, not
> the authoritative interactive prototype, and not an implementation base. Do
> not publish or distribute it as PC Steward.

PC Steward is a native Windows 11 desktop application built with **WinUI 3 and
the Windows App SDK**. The authoritative interactive design prototype is
`../native-prototype/`; production implementation belongs in
`../../src/PCSteward.Desktop`.

This browser-rendered artifact is retained only to preserve earlier visual and
state exploration. It does not inspect the computer, download updates or change
application state. Any disagreement between this archive, the native prototype,
the design specifications or the product requirements is resolved in favour of
the product requirements and native handoff.

## Historical coverage

The archive contains visual representations of first launch, scanning,
complete, no-findings, partial-provider and offline states, plus review,
applications, updates, activity and privacy/data concepts. Those representations
may be consulted for visual history only; native control behaviour, navigation,
keyboard interaction, scaling and accessibility must be judged in the WinUI
prototype and production desktop app.

**Startup** and device-wide storage analysis remain future, product-gated
concepts. The approved product scope currently covers software inventory,
WinGet-backed updates, decisions/history and PC Steward-owned data only.
