# Phase 0 — Evidence, architecture, and scaffolding

## Objective

Resolve high-impact platform and security choices with disposable spikes, then create a buildable repository skeleton. No MVP feature is considered implemented.

## Required task order

1. **Task 00:** Environment and repository audit
2. **Task 01:** Architecture, threat model, and execution plan
3. **Task 02:** Spike: packaging and WinGet integration
4. **Task 03:** Spike: privilege boundary and safe deletion
5. **Task 04:** Spike: performance baseline and fixture matrix
6. **Task 05:** Lock ADRs and architecture
7. **Task 06:** Scaffold solution and engineering guardrails

## Exit condition

OD-02, OD-03, OD-06, OD-11, and OD-13 have evidence-backed ADRs; the threat model and component boundaries are approved; the empty solution builds and tests locally.

## Scope boundaries

- Follow `AGENTS.md`.
- Do not implement Later/Never features.
- Do not begin the next phase until the phase review passes and the branch is merged.
- Requirement IDs may appear in more than one task when implementation and later hardening both provide evidence.

## Requirement and acceptance cross-reference

_No implementation requirements are claimed in this phase; it produces evidence, ADRs, and scaffolding._
