# UI inspiration reference map

Reviewed 2026-08-05. This map records pattern provenance and the original PC Steward adaptation.

| PC Steward pattern | Research references | Original adaptation | Explicit exclusions |
|---|---|---|---|
| Five-goal native shell | [PowerToys settings](https://learn.microsoft.com/en-us/windows/powertoys/general), [Windows Security](https://learn.microsoft.com/en-us/windows/security/operating-system-security/system-security/windows-defender-security-center/windows-defender-security-center) | Overview, Applications, Updates, Activity, and Settings form the stable shell; Scan, Review, Storage, Privacy, and About remain contextual destinations. | No copied labels, layouts, imagery, or module catalogue. |
| Decision-first overview | [Windows Security device health](https://support.microsoft.com/en-us/windows/security/windows-security/device-performance-and-health-in-the-windows-security-app), [Dell Command Update](https://www.dell.com/support/kbdoc/en-us/000108963/how-to-use-and-troubleshoot-dell-command-update-to-update-all-drivers-bios-and-firmware-for-your-system) | Lead with what PC Steward learned, whether a decision exists, and the next safe action; counts remain secondary. | No overall health score, green “all safe” claim, recommended-driver authority, or urgency. |
| Structured application ledger | [UniGetUI](https://github.com/Devolutions/UniGetUI), [Intune inventory](https://learn.microsoft.com/en-us/intune/app-management/discovered-apps), [Chocolatey GUI](https://docs.chocolatey.org/en-us/chocolatey-gui/) | Virtualized rows show identity, publisher, installed version, plain-English status, scope, and provider, with evidence in detail. | No package discovery store, tile default, tenant/device columns, or remote command surface. |
| Evidence detail and provenance | [UniGetUI](https://github.com/Devolutions/UniGetUI), [Intune enhanced inventory](https://learn.microsoft.com/en-us/intune/app-management/deployment/enhanced-app-inventory) | Installed and repository evidence are compared side by side; freshness, package ID, confidence explanation, mapping origin, and raw diagnostics use progressive disclosure. | No raw download URL as authority and no cloud inventory. |
| Explicit staged update journey | [Dell Command Update](https://www.dell.com/support/kbdoc/en-us/000108963/how-to-use-and-troubleshoot-dell-command-update-to-update-all-drivers-bios-and-firmware-for-your-system), [Microsoft Store updates](https://support.microsoft.com/en-us/accounts-billing/get-updates-for-apps-and-games-in-microsoft-store) | Detect → identify source → assess → select → review → approve → execute → verify is visible in copy and controls. | No automatic install, preselected restart, unattended schedule, or collapsed one-click approval. |
| Indeterminate global operation band | [UCheck scan](https://www.adlice.com/docs/ucheck/getting-started/run-a-scan/), [Microsoft Store updates](https://support.microsoft.com/en-us/accounts-billing/get-updates-for-apps-and-games-in-microsoft-store) | A persistent native progress band names the current stage, elapsed time where known, and offers Cancel only when the real workflow supports it. | No false percentage and no cancelling an uncancellable provider step. |
| Grouped settings with explanations | [PowerToys settings](https://learn.microsoft.com/en-us/windows/powertoys/general), [Chocolatey GUI settings](https://docs.chocolatey.org/en-us/chocolatey-gui/user-interface/settings/chocolatey-gui/) | Real source, schedule, notification, decision, data, and about settings are grouped with consequence text. System theme remains the default. | No invented setting, telemetry, startup agent, arbitrary source, or cosmetic dependency. |
| Bounded activity timeline | [Dell Command Update](https://www.dell.com/support/kbdoc/en-us/000108963/how-to-use-and-troubleshoot-dell-command-update-to-update-all-drivers-bios-and-firmware-for-your-system), [UCheck settings/reporting](https://www.adlice.com/docs/ucheck/getting-started/settings/) | Recent real scan, decision, mapping, and update evidence is shown as readable entries with technical detail secondary. | No enterprise log viewer, telemetry feed, or unlimited rendering. |

The PC Steward visual identity, semantic palette, logo, type scale, copy, spacing, state model, and component code remain original repository assets.
